# 拾音 Shiyin — 设计文档

基于 [ML-Netease_url](https://github.com/midairlogn/ML-Netease_url)（GPL-3.0）重写的网易云音乐解析 / 播放 / 下载工具。
本项目沿用 GPL-3.0。

## 1. 目标

- 两种形态共用一套代码：
  - **桌面版**：Tauri 2，Windows 优先（Linux 也能构建）。
  - **Web 版**：一个 Rust 单二进制，内嵌前端静态资源，自托管后用浏览器访问。
- 轻量：桌面安装包目标 < 10 MB，空闲内存目标 < 80 MB（主要是系统 WebView）；Web 二进制目标 < 15 MB，空闲内存 < 20 MB。
- 性能：首屏 JS gzip 后 < 50 KB；长列表（上千首的歌单）使用虚拟滚动；动画只用 `transform` / `opacity`。
- 界面：克制、简洁，参考 Apple 的排版、留白和动效节奏，不用液态玻璃（不做大面积 backdrop-blur 和高光折射）。

## 2. 功能范围（v1）

| 功能 | 说明 |
| --- | --- |
| 搜索 | 关键词搜索歌曲，带搜索历史和输入联想 |
| 解析 | 单曲 ID / 链接（含 163cn.tv 短链）、歌单、专辑 |
| 智能输入 | 一个输入框：粘贴链接自动识别类型，否则当作搜索词 |
| 播放 | 自研轻量播放器：播放队列、进度、音量、上一首/下一首、逐行歌词滚动（含翻译） |
| 下载 | 选择音质；写入元数据（标题、歌手、专辑、曲目号、封面、歌词）；可选外置 .lrc；文件名模板 |
| 下载管理器 | 队列、并发数、暂停 / 继续 / 取消、进度和速度 |
| 账号 | 扫码登录；或手动粘贴 MUSIC_U。凭证只保存在本机 |
| 设置 | 音质、搜索数量、并发数、文件名模板、元数据选项、下载目录（桌面版）、主题 |

上游不再保留：Flask、jQuery、Bootstrap、APlayer、命令行 GUI 模式。

## 3. 架构

```
shiyin/
├─ crates/
│  ├─ core/        # 网易云 API、eapi 加密、元数据写入、下载引擎（无 UI 依赖）
│  └─ server/      # axum HTTP 服务：/api/* + 内嵌前端（Web 版）
├─ src-tauri/      # Tauri 外壳：commands 直接调用 core
├─ web/            # Svelte 5 + Vite 前端（两种形态共用）
└─ docs/
```

### 3.1 core（Rust）

- `crypto`：eapi 参数加密（AES-128-ECB + PKCS7 + MD5 摘要），与上游 `url_v1` 等价。
- `api`：`search`、`song_detail`（批量，每批 100）、`song_url`、`lyric`、`playlist`、`album`、`qr_key`、`qr_check`、`account`。
  共享一个 `reqwest::Client`（rustls、连接复用、gzip）。
- `link`：解析输入文本，返回 `Song(id) | Playlist(id) | Album(id) | Query(text)`；短链跟随一次重定向。
- `tag`：
  - MP3：`id3` crate 写 TIT2 / TPE1 / TALB / TRCK / USLT / APIC。
  - FLAC：`metaflac` 写 Vorbis Comment 和 PICTURE 块。
  - 按文件头识别真实格式，不信任音质等级推断。
  - 封面压缩：上游在前端用 canvas 压到 640px。这里改为请求网易云图片 CDN 的 `?param=640y640`，不在本地解码图片，省掉图片库体积。
- `lrc`：时间戳规范化、原文与翻译合并（与上游 `lrctran` 规则一致）。
- `download`：
  - 桌面版：Rust 直接流式写入目标目录（先写 `.part`，完成后加标签再重命名），前端只收进度事件。
  - Web 版：服务端代理获取音频并写好标签，以附件流返回给浏览器；批量下载由服务端流式打包 ZIP。

### 3.2 传输层

前端通过 `web/src/lib/transport.ts` 调用后端，两种实现：

- `tauri`：`invoke()` + `listen()`（下载进度事件）。
- `http`：`fetch('/api/...')`。

运行时检测 `window.__TAURI_INTERNALS__` 选择实现，界面代码不感知形态差异。

### 3.3 Web 版安全

- 默认只监听 `127.0.0.1`。
- 可设置访问口令（`SHIYIN_TOKEN`）。对外暴露时必须设置，服务启动时检查。
- MUSIC_U 存在服务端数据目录，权限 0600，不回传给前端（前端只拿到昵称 / 头像 / VIP 状态）。
- 代理下载只允许网易云的音频和图片域名，防止被当作开放代理。

### 3.4 桌面版

- 单窗口，自绘标题栏区域（Windows 保留系统按钮，使用 `decorations` + 透明标题栏不必要，先用系统标题栏，减少风险）。
- 凭证存放在应用数据目录。
- 插件：`dialog`（选下载目录）、`opener`（在文件夹中显示）。
- release 配置：`opt-level = "s"`、`lto = true`、`codegen-units = 1`、`panic = "abort"`、`strip = true`。

## 4. 界面设计

### 4.1 原则

1. 内容优先：封面和歌名是视觉主体，控件退到次要位置。
2. 一种强调色，只用于当前状态和主要操作。
3. 层级靠字号、字重和留白表达，少用边框和色块。
4. 动效说明因果：元素从哪里来、回到哪里去。时长短，不反弹过度。
5. 尊重 `prefers-reduced-motion` 和系统深浅色。

### 4.2 设计令牌

| 类别 | 值 |
| --- | --- |
| 字体 | `-apple-system, BlinkMacSystemFont, "SF Pro Text", "PingFang SC", "Segoe UI Variable", "Microsoft YaHei UI", system-ui` |
| 字号 | 11 / 13 / 15（正文）/ 17 / 22 / 28 / 34（大标题），字距随字号收紧 |
| 间距 | 4 的倍数：4 8 12 16 20 24 32 48 |
| 圆角 | 6（小控件）/ 10（按钮、输入框）/ 14（卡片）/ 封面 8 |
| 浅色 | 背景 `#ffffff`，次级背景 `#f5f5f7`，文字 `#1d1d1f`，次级文字 `#6e6e73`，分隔线 `rgba(0,0,0,.08)` |
| 深色 | 背景 `#000000`/`#111113`，次级背景 `#1c1c1e`，文字 `#f5f5f7`，次级文字 `#98989d` |
| 强调色 | `#fa2d48`（接近 Apple Music 红），深色下 `#ff375f` |
| 阴影 | 只在浮层上：`0 8px 32px rgba(0,0,0,.12)` |

### 4.3 动效

| 场景 | 实现 |
| --- | --- |
| 通用缓动 | `cubic-bezier(.32,.72,0,1)`（类 iOS 弹出），时长 240–420ms |
| 页面切换 | 淡入 + 上移 8px，200ms |
| 列表进入 | 前 12 行依次延迟 18ms 出现，其余直接显示 |
| 按钮按下 | `scale(.97)`，100ms |
| 播放条 → 全屏播放页 | 封面 FLIP 动画从迷你播放条放大到大封面 |
| 歌词 | 当前行放大并提亮，整体用 `transform` 平滑滚动；其他行降低不透明度 |
| 抽屉 / 浮层 | 从边缘滑入，背景遮罩淡入；关闭时反向 |
| 进度条 | `transform: scaleX()`，不改 width |

不用 backdrop-filter 做大面积毛玻璃。顶栏和播放条使用不透明背景加一条细分隔线。

### 4.4 布局

```
┌───────────────────────────────────────────────┐
│  拾音                       [下载 ●2] [设置] [头像] │  顶栏 52px
├───────────────────────────────────────────────┤
│                                               │
│      ┌─────────────────────────────────┐      │
│      │  🔍 搜索歌曲，或粘贴歌曲/歌单/专辑链接  │      │  智能输入框
│      └─────────────────────────────────┘      │
│                                               │
│  ┌────┐ 叶惠美                                  │  合集头部（歌单/专辑）
│  │封面│ 周杰伦 · 2003 · 11 首                   │
│  └────┘ [▶ 播放全部] [↓ 下载]                    │
│                                               │
│  1  晴天          周杰伦     叶惠美      4:29  ⋯ │  歌曲列表（虚拟滚动）
│  2  ...                                        │
│                                               │
├───────────────────────────────────────────────┤
│ [封面] 晴天 · 周杰伦   ⏮ ⏯ ⏭   ━━━━○━━  🔊 ≡ 词 │  播放条 64px
└───────────────────────────────────────────────┘
```

- 空状态：输入框居中偏上，下方显示最近搜索 / 最近打开的合集。
- 列表行：悬停显示播放和下载按钮；多选模式下显示复选框。
- 全屏播放页：左侧大封面，右侧歌词；背景为封面主色的低饱和渐变（用 canvas 取一次平均色，不做实时模糊）。
- 下载管理器：右侧抽屉，分进行中 / 等待 / 已完成。
- 设置：居中面板，分组列表样式（类似 macOS 系统设置）。
- 登录：面板内显示二维码，扫码状态实时更新；底部“手动输入 MUSIC_U”。
- 窗口宽度 < 720px 时隐藏专辑列，播放条压缩。

## 5. 性能措施

- Svelte 5 编译输出，无运行时框架负担；不引入 UI 组件库和图标字体，图标为内联 SVG。
- 虚拟滚动：只渲染可视区域 ± 8 行。
- 封面按显示尺寸请求（列表 `?param=80y80`，头部 `400y400`，播放页 `800y800`），`loading="lazy"` + `decoding="async"`。
- 歌词滚动用 `requestAnimationFrame` 读取 `currentTime`，只在行变化时更新 DOM。
- 搜索输入 250ms 防抖；请求可取消。
- Rust 侧共享 HTTP 客户端，下载流式写盘，内存占用与文件大小无关。

## 6. 里程碑

1. core：加密、API、链接解析、单测（对照上游输出）。
2. server：API 路由 + 内嵌前端，Linux 上可运行。
3. 前端：令牌、布局、搜索 / 合集 / 播放 / 下载 / 设置 / 登录。
4. Tauri 外壳：命令与事件，Linux 本地构建验证。
5. GitHub Actions：Windows 安装包（NSIS）构建。
